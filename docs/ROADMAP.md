# Roadmap

1. Foundation: complete — monorepo, schema, mock workflow, secure config, CI.
2. Persistence: wire workflow services to Prisma repositories and BullMQ workers; add migrations and seed data.
3. Identity: create Supabase projects, membership provisioning, invitations, RBAC guards, and RLS tests.
4. Media: Supabase uploads, transforms, moderation, and S3/R2 adapter.
5. Live connectors: Meta and LinkedIn first, then TikTok/YouTube, X, Threads, Pinterest.
6. Operations: analytics ingestion, alerting, backups, usage billing, and tenant self-service.
